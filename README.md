 Reflection - An Interactive Portfolio of My Writing Journey

This is a responsive webpage I built to showcase my final portfolio reflections, writing progress, and research assignments from this semester. Instead of just turning in a flat document, I wanted to turn my self-reflection into an interactive digital experience using frontend development.

What This Portfolio Covers

The webpage walks through my growth as a college writer and student, highlighting:
- My Strengths & Weaknesses: How I use my imagination to structure papers (like the Ethnography assignment) versus working to make my tone less formal and more engaging.
- The Revision Process: A breakdown of how I split my editing into High-Order Concerns (fixing my thesis statement and paragraph flow after Week 7 peer reviews) and Later-Order Concerns (fixing sentence clarity, using Grammarly, and checking MLA citations).
- Honest Takeaways: What I would do differently if I took the class over—mainly starting large assignments like the Week 9 Research Proposal much earlier to allow more time for deep source analysis.

How I Built It

I wanted the layout to feel smooth and engaging as you read through it, so I combined a few different design tools:
- Bootstrap 5: Used for the responsive grid layout to make sure the text columns and images shift smoothly between desktop screens and mobile phones.
- GSAP & ScrollTrigger: Integrated these JavaScript libraries to animate the text blocks and images. Elements fade and slide into place naturally as you scroll down the page, which keeps the reading experience dynamic.
- Custom CSS: Styled the page with a clean, warm background color (`fbf3e4`) and used specific font choices like Courier New to give the headers a distinct look.
